# Task Management System

## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger

## Features
- User Registration
- User Login
- JWT Authentication
- Role Based Authorization
- Task CRUD
- Swagger API Documentation

## Run
1. Clone repository
2. Configure MySQL
3. Run TaskmanagerApplication
4. Open Swagger
